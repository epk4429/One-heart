# 02. 화면 흐름

> 화면 8단계가 무엇을 하고, 어떤 AI 역할·엔진·지식을 쓰는지 정리한다(2026-11-08 코드 기준 + 파일럿에서 바뀌는 점).
> 옛 `01 시연대본`의 화면별 대본과 CLAUDE.md 3절을 합쳐 다시 썼다. 화면 구현은 `web/js/app.js`.
> 할 일은 `00_할일.md`에만 적는다.

## 1. 기획안 9단계와 화면

| 기획안 묶음 | 기획안 단계 | 화면 |
|---|---|---|
| ① 의견 | ① 조건·선호 입력(질문 제시 → 각자 입력 → 공개 범위 선택) | 1 가족방 만들기 · 2 우리 가족 이야기 · 3 각자의 생각 |
| | ② 공동 목표 설정 | 4 공동 목표 설정 |
| ② 시뮬레이션 | ③ 미래 현금흐름·순자산 계산 | 5 미래 계산 |
| ③ 충돌 | ④ 충돌지점 · ⑤ 선택지별 재무 영향 · ⑥ 쟁점 정리·대안 | 5 미래 계산 · 6 합의안 |
| ④ 합의 | ⑦ 합의안 도출 | 6 합의안 |
| ⑤ 지속관리 | ⑧ 향후 점검 · ⑨ 이행 확인·재협의 | 7 상품 추천 · 8 가족 홈 |

기획안 13쪽 "충돌 분석·AI 합의 Agent"의 예시(VS 카드, 같은 점/갈리는 점, "날짜 대신 조건으로")는 화면 4의 내용이다. 모든 단계에 '이전 단계' 버튼이 있다.

## 2. 흐름 한눈에

메인 소개 페이지 → "서비스 이용하기"(체험 코드) → 예시 가족 또는 우리 가족 → 8단계.

```
1 가족방 ─ 2 이야기(목표 카테고리·금융정보·공개 범위) ─ 3 각자의 생각(1:1 대화 → 확인한 요약 공유)
   ─ 4 공동 목표(쟁점 → 1단계 제안 핑퐁 → 2단계 목표 숫자 정하기·모두 동의)
   ─ 5 미래 계산(방법 A·B·C) ─ 6 합의안(모두가 고른 방법 → 합의안 문서·서명)
        └ 모두가 고른 방법이 없으면 → 4 공동 목표로 돌아감(누가 무엇을 골랐는지가 수정 제안에 들어감)
   ─ 7 상품 추천(조건 비교) ─ 8 가족 홈(이행 현황·재점검·캘린더)
```

## 3. 화면별

### 1. 가족방 만들기
- 가족방 이름·이유, 구성원(이름·관계·나이·간편 모드). 구성원 2~6명.
- 파일럿: 이름은 별칭으로 안내.

### 2. 우리 가족 이야기
- **목표 카테고리 하나**(내 집 마련 / 목돈 모으기 / 대출 갚기 / 노후·은퇴 / 자녀 계획 / 부모님 부양·간병 / 기타)와 카테고리별 값. 계산에 쓰는 목표 종류·금액·기한은 이 값으로 **코드가 만든다**(AI가 정하지 않음, `llm/goals.py`). 목표 금액·기한 등은 **선택 입력**이고 비우면 화면 4의 2단계에서 정한다.
- 자유 이야기(선택), 금융정보: 마이데이터 영역(비활성) / 직접 입력, 항목마다 공개·비공개.
- AI 역할 **1a**(가족 이야기 구조화 + 구성원별 맞춤 질문 0~2개). 금융 합계는 코드가 계산.
- 쓰는 지식: 없음(G12 이름 검사만).

### 3. 각자의 생각
- 구성원별 AI 1:1 대화(메신저 모양, **본인만** 열람). 고정 질문 3개 + 가족 이야기로 만든 맞춤 질문 1~2개.
- 대화를 마치면 AI 역할 **1b**가 요약(지키고 싶은 것 / 양보할 수 있는 것 / 가장 큰 걱정 / 그 밖에 정한 것)과 말뜻 확인 필요 여부를 낸다. 애매한 말은 **그 사람과 1:1로** 되묻는다(역할 **2b** 해석, 2번까지). 끝내 확인되지 않으면 짐작하지 않고 다음 단계를 잠근다.
- 본인이 확인한 요약만 가족에게 공유된다. '나중에 답하기'를 고르면 공유 버튼 대신 '지금 답하기'만 보인다.
- 간편 모드: 쉬운 말 다시 묻기, 큰 글씨 선택형 답(음성 답변은 화면만).

### 4. 공동 목표 설정
- **쟁점 분석**(역할 **3**): 이미 같은 생각, 생각이 갈리는 부분(사람마다 자기 말 한 줄 + 차이의 종류 + 함께 지키고 싶은 것).
- **1단계 AI의 제안**(역할 **4a**): "이렇게 해 보면 어때요 → 이런 이유로 제안했어요". 근거는 문장 안에 금융꿀팁 원문 인용(누르면 원문). 서버가 모두의 '지키고 싶은 것'이 들어갔는지(covers) 검사.
  - 가족 의견: 좋아요 / 괜찮아요, 단 / 다른 의견. 의견이 있으면 수정 제안(역할 **4c**, 쪽 2/2…)이 쌓이고 이전 쪽을 다시 볼 수 있다.
  - **핑퐁은 1번까지**(2026-11-08 형님 결정, 2026-11-09 구현): 제안(쪽 1) → 의견 → 의견이 갈리면 수정 제안 1번(쪽 2). 그래도 모이지 않으면 '이야기가 필요한 부분'(역할 **4d**)을 안내하고 2단계로 못 넘어가며, 가족이 이야기를 나눈 뒤 '다시 제안받기'. 이야기를 나눈 뒤·합의안에서 돌아온 뒤의 제안은 새 차례라 다시 수정 제안 1번이 있다. 상한은 서버 `llm/pipeline.py MAX_ROUNDS_PER_CYCLE`(1)과 화면 `web/js/app.js MAX_PAGES`(2)가 같게 두고 테스트가 대조한다(임의결정 57·62).
- **2단계 목표 숫자 정하기·모두 동의**: '우리 가족 기준'(엔진, '지금처럼' 한 가지 조건: 지금 모인 돈·한 달에 모이는 돈·3/5/10년 뒤·목표가 모이는 때·기한까지 한 달에 더 필요한 돈) + '세상 기준'(내 집 마련만: 지역·집 종류별 중간 가격, 정책대출 LTV, 취득세) + AI의 '숫자를 정할 때 생각해 볼 점'(역할 **4b** `size_note`, 숫자를 정해 주지 않음)을 보며 가족이 숫자를 넣고 모두 동의한다. 기준 문장도 4b가 쓴다.
- '내용 새로고침': 쟁점·제안·숫자·동의와 이후 단계를 지우고 처음부터 다시(가족 이야기·각자 요약은 유지).

### 5. 미래 계산
- 역할 **5**(방법 설계: 공동 목표와 금융정보로 방법 A·B·C의 계산 조건) → **계산엔진** → 검증 → 역할 **6a**(결과 해석: "쉽게 말하면", 구성원별 영향).
- 방법마다 "이렇게 설계한 근거"(금융꿀팁 인용, 가정값 출처). 수익률 '예금·적금만' 3.3%는 공시 통계, 주택연금은 공사 예시표·자격 판정.
- 기본 표시는 값 하나(예: 약 4.9년), "운이 나쁠 때 / 보통 / 좋을 때"와 목표를 이룰 가능성은 보조 정보. 숫자 조절을 그래프 바로 아래에 붙여 움직이면 그래프가 바로 바뀐다(엔진만, AI 없음).
- 세 방법의 결과 차이가 3개월 미만이면 다시 설계한다.

### 6. 합의안
- 역할 **6b**(방법마다 각자의 '꼭 지키고 싶은 것'이 지켜지는지 점검표) → 각자 A·B·C 중 **괜찮은 방법을 누르기만** 한다(조건·이유 없음).
- 가족 모두가 누른 방법이 합의안이 된다. 없으면 AI 수정안·재투표 없이 **'공동 목표 설정으로 돌아가기'**(누가 무엇을 골랐는지가 자동으로 수정 제안 4c에 들어감).
- 모두가 누른 방법이 **여럿**이면(2026-11-09 형님 결정) 공동 목표 제안처럼 쪽을 넘긴다: 1/2쪽 '각자의 의사', 2/2쪽 '함께 하나 고르기'(후보 방법 카드만, 계산 결과 한 줄). 가족이 이야기한 뒤 한 사람이 눌러 정하고, 바꿀 수 있다(바꾸면 합의안을 다시 쓰고 서명을 다시 받음). **추천·자동 선택·AI 호출 없음**(어느 후보든 가족 모두 괜찮다고 한 방법이라 고정 문장으로 충분). 마지막 동의는 모두의 서명.
- 역할 **7**(합의안·합의 리포트): 목표 / 방법 / 약속 / 점검 + 목표금액·분담방식·이행시기·변경조건, 합의 이유·결과·Action Plan. 분담 금액 합 등 산술 검사. 버전 "Ver.1", 구성원별 서명(체험판은 한 기기에서 차례로).
- 점수 투표를 쓰지 않는다(다수가 소수를 이기는 구조라 합의가 아님).

### 7. 상품 추천(실제로는 조건 비교)
- 역할 **8**(약속 → 필요·제약 어휘) → 온톨로지 탐색 → 상품 유형과 "왜 이 상품인가요" 경로, 필요별 길.
- 실제 상품 목표 적합도 비교("우리 목표에 잘 맞는 순서예요"), "나에게 해당하는 것"(자녀 수·조건 7개), 제도 판정 카드, 관련 법령 찾아보기.
- 실제 상품·금융회사 이름은 **이 화면에서만** 나온다. 선택·가입은 본인.
- 파일럿: 신용·사업자대출 비교와 그래프 링크는 감춘다.

### 8. 가족 홈
- 2단(오른쪽 캘린더: 날짜 골라 일정 추가·삭제, 정기 점검 자동 표시).
- 목표 카드 아래 핵심 숫자 3칸, '지난 3개월 돈의 흐름' 표, '이대로 가면'(1·3·5년 뒤와 기한 해), 이번 달 약속. 모두 엔진 값.
- 재점검: 수입·지출 변화, 한 번에 생기거나 나간 돈, 수익률 변화, 대출 금리 변화를 넣으면 지난 합의와의 차이를 엔진으로 다시 계산(AI 없음). "이 상황으로 합의안 다시 정하기" → 미래 계산부터 다시 해 Ver.N+1.
- 파일럿: 마지막에 설문 링크와 "내 기록 지우기"(계획).

## 4. 화면 공통 규칙

- 라이트 모드 고정, 프리텐다드, 미색 종이 바탕 + 숲색 초록(#2F5D4A) 하나. "가족이 함께 쓰는 합의서" 구조(왼쪽 목차, 가운데 종이 한 장), 위에서 아래로 한 줄기.
- 강조 상자는 두 종류(AI가 하는 말 = 초록 바탕 / 내가 할 일 = 흰 바탕 테두리), 선은 두 종류.
- 금융 용어는 쉬운 말로, 어려운 용어는 점선 밑줄을 누르면 그 자리에서 풀이.
- 숫자 검증 결과는 화면에 보이지 않는다(서버에서 검사). 실제 서비스에 없는 '시연용' 버튼은 두지 않는다. 예시 가족은 대화 답·제안 답·목표 값에만 "예시 답 넣기".
- 화면 출력은 모두 이스케이프한다.

# 08. 예시 가족과 기준 데이터

> 예시 가족 두 집(신혼부부·노인 가족)의 값과 기대 출력, 가정값, 공동 목표 2단계 '통계 기준'의 출처를 정리한다(2026-11-08 문서 정리: 옛 `04 시나리오데이터` + 옛 `17 목표숫자 기준데이터 조사`).
> 두 가족은 예시 프리셋(`data/presets/`, 입력값만)이다. 파일럿 참가자는 자기 가족을 넣고, 예시 가족은 "둘러보기"용으로 남는다. 엔진 골든 케이스(`data/golden/engine_cases.json`)는 기획안 숫자를 지킨다.
> 아래 1~2절의 대사·기대 출력은 v3 프로토타입 시절 값이라, 지금 결과 숫자는 물가·이자 반영으로 조금 다를 수 있다(예: 신혼 B 약 4.2~5.3년). 레버·골든 출력은 `data/archive/scenarios_v3/`.

- 인물·대사·숫자의 원본은 v3 프로토타입의 `DATA`, `CONSENT`, `CALC` 객체다. 이 문서는 구현에 필요한 **구조화 값**과 **기대 출력(골든 값)**을 정리한다. 대사 전문은 v3를 따른다.
- ✅ 모든 금액·인물·금융사는 가상이다. 단위는 만원.

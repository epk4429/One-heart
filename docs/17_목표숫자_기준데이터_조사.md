# 17. 공동 목표 2단계 '세상 기준' 기준 데이터 출처 조사 (2026-11-08)

> 목적: 공동 목표 설정 2단계에서 목표 숫자를 정할 때 '우리 가족 기준'(엔진, 구현 완료) 옆에 보여 줄 공공 기준값의 출처가 실제로 있는지 확인한다.
> 방법: 웹 검색 + 공식 페이지·원문 받기(비용 0). **확인한 것과 확인 못 한 것을 나눠 적는다.** 모두 확보하는 게 목표가 아니라, 되는 데까지 하고 안 되는 것은 '확보 못 함'으로 남긴다(2026-11-08 형님 지시).

## 다음 단계 제안

1. ~~부동산원 통계표 확인~~ → 완료(2026-11-08). 새 달 통계는 `python tools/fetch_reb_prices.py --seq <첨부번호> --label YYYYMM`(첨부 번호는 e-나라지표 페이지의 파일 링크에 있음).
2. 원문이 있는 것부터 수집: 정책대출 LTV(이미 있음) → 장기요양 고시 → 취득세 법령 → 노후패널 보고서 → 보육실태조사 보고서.
3. 기존 방식대로 원본을 `knowledge/sources/`에 날짜를 붙여 보관하고, 코드가 기준값을 뽑아 `data/reference/benchmarks.json`(가칭)에 넣고, 원본 숫자 일치 테스트를 둔다.
4. 화면에는 기관·조사 이름·기준 시점을 함께 보여 주고, '인식 조사'·'가구 단위'처럼 숫자의 성격을 한 줄로 밝힌다.
5. 화면에 붙일 때 스냅샷 JSON을 `vercel.json` includeFiles에 더한다(원본 xlsx는 넣지 않음).

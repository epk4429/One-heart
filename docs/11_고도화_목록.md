## B. 미뤄 둔 기능 결정

| | 항목 | 내용 |
|---|---|---|
| 🟡 | **D1. 공동 목표 재제안** | 가족이 AI 제안에 다른 의견을 내도 지금은 그냥 다음 단계로 넘어감. 안: 의사 버튼(좋아요/단/다른 의견) → AI 수정 제안 → 재동의, 상한 2회(CLAUDE.md 10절) |
| 🟡 | 1:1 대화의 깊이 | 지금은 고정 질문 3개 + 필요할 때 말뜻 되묻기. AI가 답에 따라 꼬리 질문을 하는 자유 대화는 안 함(임의결정 13, 비용·범위) |
| 🟡 | 반대 없는 방법이 여럿일 때 | 지금은 첫 번째로 진행. 실제로는 그중 하나를 함께 고르는 질문이 필요 |
| 🟡 | 수정안 상한 | 수정안은 1번까지. 그래도 반대면 "의사 다시 남기기"만 있음 |
| 🟡 | 공개본에서 "우리 가족" 열기 | `ALLOW_CUSTOM_FAMILY=1`로 열 수 있음. 열 때는 실제 정보 입력·Anthropic 데이터 보관 안내를 다시 다듬어야 함 |
| 🟡 | 모델 섞어 쓰기 | 어려운 단계(공동 목표 제안·방법 설계)만 Opus, 나머지 Sonnet → 한 가족 약 $0.4 예상(측정 안 함) |
| 🟡 | 숫자 검증 표시 | 화면에서 숨김(사용자 결정). 심사용으로 보여 줄 "심사 모드"를 둘지 |

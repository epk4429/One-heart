## 4. 화면 · 기능

### 결정했고 만들 것
- [ ] **각자의 생각 맞춤 질문**: 고정 질문 3개는 그대로 두고, 가족 이야기를 보고 그 사람에게 필요한 질문 1~2개를 더한다. 예: 이야기에 "내년 육아휴직" → "휴직은 몇 개월쯤 생각하세요?". 다른 가족의 대화는 보지 않는다(4절 1번). 가능하면 기존 AI 호출에 합쳐 비용을 늘리지 않는다. 체험판은 재생 공급자(`llm/replay.py`)에 맞춤 질문 규칙도 넣는다. 💰

### 체험 중 발견했지만 아직 안 고친 문제 (docs/11 A)
- [ ] 노인 가족에서 A·B 방법이 모두 "28년 이상"으로 표시돼 구분이 안 된다. 남는 예금·가장 적을 때 예금을 함께 보여 줘야 한다.
- [ ] 수정안 같은 AI 출력의 사람 이름을 가족 구성원 이름과 대조하는 검사가 없다.
- [ ] 공개 모드 우회: 금융정보는 API를 직접 부르면 바꿀 수 있다.
- [ ] 재협의(Ver.2)에 수익률 변화가 반영되지 않는다.
- [ ] 실제 AI로 다시 확인하지 못한 수정: 조사 교정, "월 월", 상품 조건 합치기, '한 번에 갚기', 결과 차이 검사, 캐시. 💰

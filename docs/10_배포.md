# 10. 배포 안내 (공개 체험판)

> 2026-10-07 작성. 코드 쪽 준비는 끝났다(아래 1절). 2절부터는 계정·키가 필요해서 형님이 직접 한다.
> Claude는 API 키를 입력하거나 계정을 만들지 않는다. 커밋·푸시·공개는 형님이 확인한 뒤에만 한다.

## 1. 준비된 것 (코드)

| 항목 | 내용 |
|---|---|
| Vercel 진입점 | `api/index.py` 하나만 함수가 된다. 서버 코드는 `server/`로 옮김 |
| 실행 시간 | `vercel.json` maxDuration 300초(Hobby 최대 300초, 미래 계산은 30~60초) |
| 데이터 파일 | 가정값 표·예시 가족·온톨로지를 함수에 포함(`includeFiles`) |
| 화면 | Vercel 하나로 올리면 `web/`이 첫 화면(`outputDirectory`) → **링크 하나로 끝** |
| GitHub Pages(선택) | 2026-10-07 방식 A(Vercel 하나, 비공개 저장소)로 정해서 Pages 자동 배포 설정은 지웠다(비공개 저장소에서 매번 실패해 "deploy failed" 메일이 옴). B로 바꾸려면 Pages 워크플로를 다시 넣고, `web/js/config.js`의 `VERCEL_API`와 Vercel `ALLOWED_ORIGIN`을 맞춘다 |
| 보호 장치 | 체험 코드·코드별 예산·전체 예산·IP당 1분 20회·입력 길이 제한(`server/guard.py`) |
| 비밀값 | `.env`, `data/usage/`는 저장소에 올라가지 않음(`.gitignore`). 저장소에서 키 문자열을 찾아봤고 없었음 |

## 2. 방식 고르기

- **A. Vercel 하나(추천):** 화면과 서버가 같은 주소. 링크 하나(`https://프로젝트이름.vercel.app`). 저장소를 **비공개**로 둬도 된다(기획 문서가 공개되지 않음).
- **B. GitHub Pages + Vercel(처음 계획):** 화면은 `https://아이디.github.io/저장소`, 서버는 Vercel. 무료 Pages는 저장소가 **공개**여야 한다.

## 3. 형님이 할 일 (A 기준)

1. **Anthropic 콘솔**에서 월 사용 한도를 건다(남은 크레딧 이상 쓰지 않게). 체험 한 번에 약 $0.2(Sonnet 5.5) → 남은 크레딧으로 몇 번 가능한지 계산해 두기.
2. **GitHub**에 새 저장소를 만든다(A면 비공개 가능). 만든 뒤 저장소 주소를 Claude에게 알려 주면, Claude가 첫 커밋을 만들고 올릴 명령을 준비한다(올리기는 형님 확인 후).
3. **Vercel**(vercel.com)에 GitHub로 로그인 → Add New → Project → 저장소 Import.
   - Framework Preset: **Other**, Build Command·Output은 비워 둔다(`vercel.json`이 정함).
4. Vercel 프로젝트 → Settings → **Environment Variables**에 넣는다(키 값은 형님이 직접):

| 이름 | 값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (콘솔에서 발급한 키) | 화면·저장소에는 절대 넣지 않음 |
| `LLM_PROVIDER` | `anthropic` | |
| `LLM_MODEL` | `claude-sonnet-5-5` | |
| `ACCESS_CODES` | 예: `judge2026:1.0,friend:0.4` | 콜론 뒤는 그 코드로 쓸 수 있는 AI 비용(달러). 비우면 코드 없이 누구나 |
| `CODE_BUDGET_USD` | `0.5` | 콜론 없이 적은 코드의 기본 예산 |
| `BUDGET_USD` | 예: `2.5` | 전체 AI 비용 상한(달러). 넘으면 AI 기능이 멈춤 |
| `RATE_PER_MIN` | `20` | IP당 1분 요청 수 |
| `ALLOWED_ORIGIN` | (B 방식일 때만) Pages 주소 | |

5. (권장) Vercel 프로젝트 → Storage(또는 Marketplace) → **Upstash Redis** 무료로 연결. 연결하면 환경변수가 자동으로 붙는다(`UPSTASH_REDIS_REST_*` 또는 `KV_REST_API_*`, 둘 다 인식).
   - 없으면 예산 합계가 서버 인스턴스마다 따로 세져서 상한이 정확하지 않다. 그때는 1번의 콘솔 한도가 실제 안전장치다.
6. Deploy → 나온 주소를 Claude에게 알려 주면 Claude가 접속해 확인한다(상태 확인 → 예시 가족 한 번, 약 $0.2).

## 4. 배포 뒤 확인할 것

- `https://주소/api/health` → `"provider": "anthropic"`, `"access_required": true`
- 체험 코드 없이 AI 단계를 누르면 코드 입력 화면이 뜨는지
- 예시 가족으로 끝까지 한 번(시간 초과·오류 없는지)
- 비용: 호출별 장부(`calls.jsonl`)는 로컬 전용이다. 배포본의 실제 비용은 Anthropic 콘솔 Usage에서 본다.

## 5. 녹화본 체험판 (돈 안 드는 예시 체험, 2026-11-01)

- 파일 하나: `web/demo.html`. **비공개**(2026-11-02 형님 결정): `.vercelignore`로 Vercel 배포에서 빼고, 로컬 개발 서버(`/demo.html`)나 파일로만 연다(인터넷은 글꼴·Pyodide에만 씀). 개발용 실제 상품 공시 데이터도 들어 있다.
- AI 단계는 실제 Claude로 예시 가족 두 집을 진행하며 녹화한 응답(`data/demo/rec/*.jsonl`)을 기다림 없이 바로 보여 준다. 계산·검사는 서버 Python 코드를 브라우저 안의 Pyodide로 그대로 돌린다(처음 열 때 약 10MB, 3초 안팎). AI 호출이 없어 비용이 0이고 체험 코드도 필요 없다.
- 녹화본이라 답·목표·의사 표시는 예시 그대로만 진행되고, 합의안 다시 정하기(AI)는 막혀 있다. 미래 계산 슬라이더와 가족 홈 재점검은 실제로 계산된다.
- 다시 만들기(프롬프트나 응답 형식이 바뀌었을 때):
  1. 녹화 파일을 지우고 `python dev_server.py 8768 --record data/demo/rec/demo.jsonl` (실제 Claude, 약 $0.5)
  2. 예시 가족 두 집을 처음부터 상품 추천까지 진행. 말뜻 되묻기는 1번 답, 의사 표시는 `data/demo/stances.json`과 같게
  3. `python tools/build_demo.py` → `web/demo.html`, `python -m pytest tests/test_demo.py`

# 09. 시스템 구성과 배포

> 부품 배치, API, LLM 공급자 교체 구조, 개발·배포 방법(2026-11-08 기준). 옛 `09 시스템구성`과 `10 배포`를 합쳤다. 원본은 `docs/archive/`.
> 할 일은 `00_할일.md`에만 적는다.

## 1. 부품 배치

```
[브라우저 · PC]  web/ (빌드 없는 바닐라 JS)  · 입력·진행 상태는 localStorage에만
        │  fetch(JSON)
        ▼
[Vercel 함수 하나]  api/index.py → server/app.py
        ├─ 보호 장치  server/guard.py (체험 코드·예산·호출 제한·입력 길이)
        ├─ 입력 검사·금융 합계  llm/family.py
        ├─ AI 역할  llm/ (공급자 어댑터·역할·파이프라인·근거)
        ├─ 계산엔진  engine/      (04_계산엔진.md)
        ├─ 숫자 검증 verify/      (05_AI역할과_검증.md)
        ├─ 온톨로지  ontology/    (06_온톨로지와_RAG.md)
        └─ RAG       rag/
  데이터: data/assumptions.json, data/presets/, ontology/*.json, knowledge/
  예산 합계: Upstash Redis
```

- 서버는 아무것도 저장하지 않는다(로그인·DB 없음). 한 기기에서 '보는 사람'을 바꿔 가며 가족이 돌아가며 입력한다.
- 엔진은 서버(Python)에 하나만 두고, AI 도구 호출과 화면 슬라이더가 같은 엔진을 쓴다.
- 환경 메모: 개발 PC에 Node.js가 없다. 기본 `python`은 anaconda Python 3.13(pytest 포함).

## 3. API

모두 JSON. 요청에 체험자의 가족 입력(`family`)을 보내고 서버가 매번 `llm/family.py`로 검사한다. AI를 쓰는 API는 `X-Access-Code` 헤더(체험 코드)·예산·호출 제한을 거친다.

| 엔드포인트 | 화면 | 처리 |
|---|---|---|
| `GET /api/health` | 공통 | 공급자·모델, 엔진 버전, 체험 코드 필요 여부 |
| `/api/access` | 시작 | 체험 코드 확인, 남은 사용량 |
| `/api/config` | 공통 | 고정 질문, 금융 항목 종류, 목표 카테고리, 가정값 표, 필요별 길 |
| `/api/preset` | 시작 | 예시 가족 |
| `/api/family/check` | 2 | 입력 검사 + 금융 합계(AI 없음) |
| `/api/story/understand` | 2 | 역할 1a |
| `/api/interview/review`, `/api/interview/resolve` | 3 | 역할 1b, 2b |
| `/api/goal/analyze`, `/api/goal/revise`, `/api/goal/stuck` | 4 | 역할 3 → 4a, 4c, 4d |
| `/api/goal/size`, `/api/goal/criterion`, `/api/goal/check` | 4 | 우리 가족 기준·통계 기준, 역할 4b, 목표 검사 |
| `/api/options/design` | 5 | 역할 5 → 엔진 → 역할 6a → 검증 |
| `/api/simulate` | 5, 8 | 엔진만 |
| `/api/agreement/check`, `/api/agreement/draft` | 6 | 역할 6b, 역할 7 → 검증 |
| ~~`/api/agreement/revise`~~ | (뺌) | 2026-11-09 공개 주소에서 뺌(404). 역할 5r 코드는 남김(임의결정 64) |
| `/api/recommend`, `/api/products/fit`, `/api/programs/judge`, `/api/rag/search` | 7 | 역할 8 → 온톨로지, 적합도 비교(금리·이자는 엔진), 제도 판정(주택연금 예상 월지급금은 엔진 값을 서버가 붙임), 법령 찾기(`laws`로 법령 좁히기, `topic: true`면 낱말 일부만 맞아도) |
| `/api/graph/*` | (그래프 화면) | 온톨로지 그래프 |
| `/api/review/compare` | 8 | 재점검(엔진) |

오류: `{error: {code, message}}`, AI 실패 시 `llm_unavailable` → 화면에 "다시 시도".

## 4. LLM 어댑터

```python
class LLMProvider:
    def complete(self, system, messages, json_schema=None, tools=None, max_tokens=1500, ...) -> LLMResult
# LLMResult: {text, json, tool_calls, usage, model}
```

| 구현 | 쓰임 |
|---|---|
| `AnthropicProvider` | 실제 서비스. 공식 SDK `anthropic`(서버 의존성 중 유일한 외부 패키지). `ANTHROPIC_API_KEY`, `LLM_MODEL=claude-sonnet-5-5`, `LLM_EFFORT` |
| 재생 공급자 | 개발·mock 체험판. 규칙으로 만든 예시 답 |
| `HFProvider` | 남아 있지만 쓰지 않음 |

## 5. 로컬 개발

```bash
python dev_server.py 8000            # 실제 Claude(.env의 ANTHROPIC_API_KEY)
python dev_server.py 8000 --replay   # 돈 안 드는 개발용
python dev_server.py 8000 --budget 6.5   # 그 실행에만 예산 상한을 바꿈
python -m pytest tests/
python -m server.usage_report        # 호출별 비용 장부(로컬만)
```

- 개발 서버는 서버 쪽 파일(.py·.json·.env)이 바뀌면 스스로 다시 켜지고, 같은 포트에 두 개 뜨지 않게 막는다.
- 로컬 기본값: 체험 코드 없음, 전체 AI 비용 상한 `BUDGET_USD=6.0`, IP당 1분 20회. 모든 실제 호출 비용은 `data/usage/usage.json`에 쌓이고 상한을 넘으면 막힌다.

## 6. 배포 (Vercel 하나)

- 공개 주소 https://one-heart-nine.vercel.app, 비공개 저장소 epk4429/One-heart, Upstash 예산 저장 연결. 커밋·푸시·배포는 형님이 직접 한다.
- `vercel.json`: maxDuration 300초, `outputDirectory: web`, `includeFiles`에 가정값·예시 가족·온톨로지·상품 노드·원문(`knowledge/sources/index.json`, `docs/*.txt`)·RAG 조각. 공시 원본 json은 넣지 않는다. 새 데이터 파일을 서버가 읽게 하면 여기에 더한다.
- 환경변수(형님이 Vercel에 직접 넣음):

| 이름 | 값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 콘솔에서 발급 | 화면·저장소에 절대 넣지 않음 |
| `LLM_PROVIDER` / `LLM_MODEL` | `anthropic` / `claude-sonnet-5-5` | |
| `ACCESS_CODES` | 예: `family01:0.6,family02:0.6` | 콜론 뒤는 그 코드의 AI 비용 상한(달러). 파일럿은 참가 가족마다 하나 |
| `CODE_BUDGET_USD` | 예: `0.5` | 콜론 없이 적은 코드의 기본 예산 |
| `BUDGET_USD` | 예: `2.5` | 전체 AI 비용 상한 |
| `RATE_PER_MIN` | `20` | IP당 1분 요청 수 |
| `ALLOW_CUSTOM_FAMILY` | 비워 둠 / `0` | 직접 만든 가족('우리 가족')을 받을지. **2026-11-09부터 체험 코드와 묶임**(임의결정 66): 비워 두면 `ACCESS_CODES`가 있을 때 열리고(가족 정보를 담은 요청은 AI를 안 써도 맞는 코드가 있어야 함), 코드가 없으면 Vercel에서는 닫힘(`1`이어도). `0`이면 언제나 닫힘. **파일럿: 이 변수는 비우고(`0`이면 지우고) `ACCESS_CODES`만 넣는다** |
| `REAL_PRODUCTS` | (비우면 켜짐) | `0`이면 실제 상품 비교를 끔 |

- 배포 뒤 확인: `/api/health`의 provider·access_required, 코드 없이 AI 단계를 누르면 코드 입력 화면이 뜨는지, 예시 가족 한 번 끝까지. 배포본 비용은 Anthropic 콘솔 Usage에서 본다.
- QR코드: `docs/qr/`.

## 7. mock 체험판 (`web/demo.html`, 공개 `/demo.html`)

- 예시 가족 두 집을 **비용 없이** 끝까지. 모든 단계를 서버 Python 코드로 브라우저 안의 Pyodide(처음 약 10MB)에서 돌리고, AI 단계는 재생 공급자의 mock 답이다. 체험 코드 필요 없음.
- 녹화본이 아니므로 코드·온톨로지·가정값을 바꾼 뒤 `python tools/build_demo.py` → `python -m pytest tests/test_demo.py`만 하면 된다. 예전 녹화 파일(`data/demo/rec/`)과 `dev_server.py --record`는 남아 있지만 쓰지 않는다.

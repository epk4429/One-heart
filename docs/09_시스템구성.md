# 09. 시스템 구성·API 명세

> **2026-10-06 체험판 전환:** 모든 API는 `room_id` 대신 체험자의 가족 입력(`family`)을 받고, 서버는 매번 `llm/family.py`로 검사한다. AI를 쓰는 API는 `X-Access-Code` 헤더(체험 코드)·예산·호출 제한을 거친다(`server/guard.py`). 아래 3절 표를 갱신했다.

## 1. 부품 배치

```
[브라우저 · PC]
  GitHub Pages(정적)  ── web/ (바닐라 JS, v3 디자인)
        │  fetch(JSON)  · 상태는 localStorage
        ▼
[서버리스 · Vercel Python 함수]  api/

        ├─ LLM 어댑터 ── Hugging Face(OpenAI 호환) | Anthropic
        ├─ 계산엔진  engine/   (05)
        ├─ 검증 구조 verify/   (07)
        └─ 온톨로지  ontology/ (08)
  정적 데이터: data/scenarios/*.json, data/assumptions.json, ontology/*.json
```

| 결정 | 상태 |
|---|---|
| 프론트는 GitHub Pages | ✅ |
| LLM 호출은 서버리스, 키는 서버리스에만 | ✅ |
| 공급자 교체 구조(개발 HF 오픈소스 → 통합 테스트부터 Anthropic) | ✅ |
| 프론트는 빌드 없는 바닐라 JS, 서버리스는 Vercel Python 함수 | ⚠️ 제안(CLAUDE.md 9절) |
| 로그인·DB 없음, 상태는 브라우저 | ⚠️ 제안 |
| 엔진·검증·온톨로지를 LLM과 같은 서버리스 안에 둔다 | ⚠️ 제안(왕복 횟수를 줄이고 키 없이도 엔진을 쓸 수 있게) |

## 3. API

모두 `POST`, JSON 요청/응답. 상태는 클라이언트가 필요한 부분을 보내고 서버는 저장하지 않는다(PoC). 응답에는 LLM을 쓴 경우 항상 `verification`(07 7절)이 붙는다.

구현: `server/app.py`(라우트), `api/index.py`(Vercel), `dev_server.py`(로컬). 2026-10-06 기준 실제 목록.

| 엔드포인트 | 화면 | 내부 처리 |
|---|---|---|
| `GET /api/health` | 공통 | 공급자·모델, 엔진 버전, 체험 코드 필요 여부 |
| `/api/access` | 시작 | 체험 코드 확인, 남은 사용량(%) |
| `/api/config` | 공통 | 고정 질문 3개, 금융 항목 종류, 대출 종류, 목표 종류, 가정값 표 |
| `/api/preset` | 시작 | 예시 가족(입력값 + 예시 답) |
| `/api/family/check` | 2 | 가족 입력 검사 + 금융 합계(코드 계산), AI 없음 |
| `/api/story/understand` | 2 | 역할 1a |
| `/api/interview/review` | 3 | 역할 1b(요약 + 말뜻 확인 필요 여부). 재질문 결과가 있으면 다시 요약 |
| `/api/interview/resolve` | 3 | 역할 2b |
| `/api/goal/analyze` | 4 | 역할 3 → 4a |
| `/api/goal/criterion` | 4 | 역할 4b(기준 문장 + 계산할 목표 제안, 목표 금액 근거 검사) |
| `/api/goal/check` | 4 | 가족이 고친 목표 검사(출발 금액·계산 기간), AI 없음 |
| `/api/options/design` | 5 | 역할 5(엔진 도구, 출처 검사) → 엔진 → 역할 6a → 검증 |
| `/api/simulate` | 5(슬라이더), 8 | 엔진만(방법 spec 다시 검사) |
| `/api/agreement/check` | 6 | 역할 6b → 검증 |
| `/api/agreement/revise` | 6 | 역할 5r → 출처 검사 → 엔진 → 검증 |
| `/api/agreement/draft` | 6 | 역할 7 → 검증(분담 합계·조건 반영) |
| `/api/recommend` | 7 | 역할 8 → 검증 → 온톨로지 탐색(중복 정리) |
| `/api/review/compare` | 8 | 엔진 compare(수익률 가정 변화) |

공통 요청 필드: `{family, ...단계별 값}`. 공통 오류: `{error: {code, message}}`, LLM 실패 시 `code: "llm_unavailable"` → 화면에 "다시 시도".

## 4. LLM 어댑터

```python
class LLMProvider:
    def complete(self, system: str, messages: list, json_schema: dict | None = None,
                 tools: list | None = None, max_tokens: int = 1500, temperature: float = 0.1) -> LLMResult: ...
# LLMResult: {text, json, tool_calls, usage: {input_tokens, output_tokens}, model}
```

| 구현 | 엔드포인트 | 환경변수 |
|---|---|---|
| `HFProvider` | Hugging Face Inference Providers(OpenAI 호환 chat completions) | `HF_TOKEN`, `LLM_MODEL` |
| `AnthropicProvider` | Anthropic Messages API, 공식 SDK `anthropic`(tool use 지원, 거절 시 서버 쪽 대체 모델) | `ANTHROPIC_API_KEY`, `LLM_MODEL`(기본 `claude-opus-5-5`), `LLM_EFFORT`(기본 medium) |

- 선택: `LLM_PROVIDER=anthropic|hf|replay`. 프롬프트·스키마·검증은 공급자와 무관하게 같다.
- 역할 5의 tool 호출: 공급자가 tool을 지원하면 tool 루프(최대 3회), 아니면 "JSON만 받고 서버가 엔진 호출" 모드로 자동 전환(06 9절 2번).
- Anthropic 모델은 `claude-opus-5-5`(임의결정 19). 오픈소스 모델 선정은 HF 크레딧 소진으로 중단.
- Claude 쪽 대화 기록은 덧붙이기만 한다: 역할 실행 중 도구 목록을 바꾸지 않고, 도구 왕복·재요청 때 이전 응답(생각 블록 포함)을 그대로 되돌려 준다(`llm/runner.py`, 임의결정 22).
- 요금: ✅ 나중에 API 토큰 제한으로 막는다. 어댑터에 호출당 `max_tokens` 상한과 사용량 로그만 둔다.

## 5. 개발·배포

| 단계 | 방법 |
|---|---|
| 로컬 개발 | Node.js가 없으므로(환경 메모) `python dev_server.py`로 `web/` 정적 파일과 `api/` 핸들러를 한 포트(예: 8000)에서 같이 띄운다. Vercel 함수와 같은 핸들러 코드를 import한다 |
| 테스트 | `python -m pytest tests/` — 엔진 수용 테스트(05 5절)가 첫 번째 관문 |
| 배포(나중) | GitHub 원격 저장소 생성 → GitHub Pages(`web/`) + Vercel(GitHub 연동으로 `api/` 배포, CLI 불필요) |
| 설정 | 프론트 `web/js/config.js`의 `API_BASE`를 배포 주소로. Vercel에서 CORS 허용 출처를 GitHub Pages 주소로 제한 |

🔲 확인 필요: Vercel Python 런타임이 지원하는 Python 버전, 함수 최대 실행 시간(역할 5 tool 루프는 수십 초가 걸릴 수 있음, `vercel.json`의 `maxDuration` 설정). 코드는 Python 3.12 문법 안에서 쓴다(⚠️).

## 6. 시연 모드

- `web/js/config.js`의 `DEMO_MODE=true`일 때: 다른 구성원의 입력을 각본(`data/scenarios`)에서 넣는 "시연용" 버튼을 보여 준다(✅ 4절 9번: 실제 서비스에는 없음).
- LLM 응답 지연에 대비해 화면마다 "AI가 정리하고 있어요" 상태를 둔다. ⚠️ 녹화 시연이면 실시간 호출을 그대로 보여 주고, 지연이 길면 편집으로 줄인다.
